# Example Application using Youtube API

## Running the Application
To run the application, follow these steps:

- Compiled application will be placed in `bin` folder.
- Add `libeay32.dll` and `ssleay32.dll` files to `bin` folder
- Get API key from Google Cloud Console
- Create `YoutubeApiTests.ini` file in `bin` folder with following content:
  
  ```
  [Google]
  Key=<Key>
  ```
